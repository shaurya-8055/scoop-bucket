# Scoop bucket

Apps by Shaurya Shakya for [Scoop](https://scoop.sh).

```powershell
scoop bucket add snapfloat https://github.com/shaurya-8055/scoop-bucket
scoop install snapfloat
```

| App | What it is |
|---|---|
| [SnapFloat](https://github.com/shaurya-8055/snapfloat) | The macOS screenshot thumbnail for Windows: drag screenshots into any app, mark them up, copy text, blur private info |

Update with `scoop update snapfloat`. `scoop uninstall snapfloat` also removes its autostart entry and settings.
